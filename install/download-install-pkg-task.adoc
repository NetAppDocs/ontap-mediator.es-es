= Descarga el paquete de instalación de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Descarga el paquete de instalación de ONTAP Mediator e instálalo.

.Pasos
. Descarga el paquete de instalación de ONTAP Mediator desde la página de descargas de ONTAP Mediator.
+
https://mysupport.netapp.com/site/products/all/details/ontap-mediator/downloads-tab["Página de descarga de ONTAP Mediator"^]

. Coloca el paquete de instalación de Mediator en el directorio de trabajo actual:
+
[source, cli]
----
ls ontap-mediator-1.12.1.tgz
----
+
....
ontap-mediator-1.12.1.tgz
....
+

NOTE: En las versiones 1.4 y anteriores de ONTAP Mediator, el instalador se llama  `ontap-mediator`.

+
Si tu sistema no tiene conexión a internet, asegúrate de que el instalador pueda acceder a los paquetes necesarios.

. Si es necesario, traslada el paquete de instalación de Mediator al directorio de instalación.
. Descomprime el paquete de instalación:
+
[source, cli]
----
tar xvfz ontap-mediator-1.12.1.tgz
----
+
....

ontap-mediator-1.12.1/tsa-prod-ONTAP-Mediator.pem
ontap-mediator-1.12.1/tsa-prod-chain-ONTAP-Mediator.pem

ontap-mediator-1.12.1/ontap-mediator-1.12.1

ontap-mediator-1.12.1/ontap-mediator-1.12.1.tsr
ontap-mediator-1.12.1/ontap-mediator-1.12.1.sig
....
