= Proporcionar acceso al repositorio para la instalación de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Debes habilitar el acceso a los repositorios para que ONTAP Mediator pueda acceder a los paquetes necesarios durante el proceso de instalación.

.Pasos
. Determina a qué repositorios debes acceder, como se muestra en la siguiente tabla:

. Utiliza uno de los siguientes procedimientos para habilitar el acceso a los repositorios mencionados arriba, así ONTAP Mediator puede acceder a los paquetes necesarios durante el proceso de instalación.
+

NOTE: Si ONTAP Mediator depende de módulos de Python presentes en los repositorios "extras" y "optional", es posible que necesite acceder a los archivos `rhel-X-for-x86_64-extras-rpms` y `rhel-X-for-x86_64-optional-rpms`.

+
.Procedimiento para el sistema operativo Oracle Linux 10.x
[%collapsible]
====
Usa este procedimiento si tu sistema operativo es *Oracle Linux 10.x* para habilitar el acceso a los repositorios:

.Pasos
.. Suscríbete al repositorio requerido:
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
----
+
[source, cli]
----
subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
----
+
El siguiente ejemplo muestra la ejecución de este comando:

+
[listing]
----
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-baseos-rpms
Repository 'ol-10-for-x86_64-baseos-rpms' is enabled for this system.
[root@localhost ~]# subscription-manager repos --enable ol-10-for-x86_64-appstream-rpms
Repository 'ol-10-for-x86_64-appstream-rpms' is enabled for this system.
----
.. Ejecuta el siguiente comando para ver la lista de repositorios habilitados:
+
[source, cli]
----
yum repolist
----
+
Los repositorios recién suscritos deberían aparecer en la lista.

.Procedimiento para el sistema operativo CentOS 7.x
[%collapsible]
====
Usa este procedimiento si tu sistema operativo es *CentOS 7.x* para habilitar el acceso a los repositorios:


NOTE: Los siguientes ejemplos muestran un repositorio para CentOS 7.6 y es posible que no funcionen con otras versiones de CentOS. Utiliza el repositorio base para tu versión de CentOS.

.Pasos
.. Añade el repositorio C7.6.1810 - Base. El repositorio C7.6.1810 - Base vault contiene el paquete "kernel-devel" necesario para ONTAP Mediator.
.. Agrega las siguientes líneas a /etc/yum.repos.d/CentOS-Vault.repo.
+
[source, cli]
----
[C7.6.1810-base]
name=CentOS-7.6.1810 - Base
baseurl=http://vault.centos.org/7.6.1810/os/$basearch/
gpgcheck=1
gpgkey=file:///etc/pki/rpm-gpg/RPM-GPG-KEY-CentOS-7
enabled=1
----
.. Ejecuta el siguiente comando para ver la lista de repositorios habilitados:


[source, cli]
----
yum repolist
----

.Procedimiento para los sistemas operativos Rocky Linux 10, 9 u 8
[%collapsible]
====
Sigue este procedimiento si tu sistema operativo es *Rocky Linux 10*, *Rocky Linux 9* o *Rocky Linux 8* para habilitar el acceso a los repositorios:

.Pasos
.. Suscríbete a los repositorios necesarios:
+
[source, cli]
----
dnf config-manager --set-enabled baseos
----
+
[source, cli]
----
dnf config-manager --set-enabled appstream
----
.. Realiza una operación de  `clean`:
+
[source, cli]
----
dnf clean all
----
.. Verifica la lista de repositorios:
+
[source, cli]
----
dnf repolist
----


....
[root@localhost ~]# dnf config-manager --set-enabled baseos
[root@localhost ~]# dnf config-manager --set-enabled appstream
[root@localhost ~]# dnf clean all
[root@localhost ~]# dnf repolist
repo id                        repo name
appstream                      Rocky Linux 10 - AppStream
baseos                         Rocky Linux 10 - BaseOS
[root@localhost ~]#
....
