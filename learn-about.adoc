= Conoce ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ./media/


[role="lead"]
ONTAP Mediator admite las funciones de ONTAP al proporcionar un almacenamiento persistente y protegido para los metadatos de alta disponibilidad (HA), una funcionalidad de consulta síncrona del estado de los nodos para facilitar la determinación del quórum y al actuar como proxy de ping para comprobar la capacidad de respuesta de las controladoras.


NOTE: Esta documentación se refiere a la versión local de ONTAP Mediator. Para obtener información sobre ONTAP Cloud Mediator, disponible a partir de ONTAP 9.17.1, consulta link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html["SnapMirror documentación de active sync"^].



[[how-ontap-mediator-works]]
== Cómo funciona ONTAP Mediator

ONTAP Mediator se ejecuta en un host Linux situado en un tercer dominio de fallo, independiente de tus clústeres de ONTAP, donde proporciona un almacén persistente y aislado para los metadatos de alta disponibilidad. ONTAP utiliza este almacén, junto con las funciones de consulta del estado de los nodos y de proxy de ping de Mediator, para supervisar las relaciones de sincronización activa de SnapMirror y las configuraciones IP de MetroCluster.

* ONTAP Mediator utiliza el LIF de gestión de nodos y el LIF de gestión de clúster para comunicarse con cada clúster a través de múltiples rutas redundantes. Esto permite a ONTAP distinguir entre un fallo total del sitio y un único fallo de enlace InterSwitch (ISL).
* En la sincronización activa de SnapMirror, si un clúster pierde la conexión tanto con su par como con ONTAP Mediator, ONTAP considera que el par es inaccesible y puede conmutar automáticamente a la copia superviviente.
* En las configuraciones IP de MetroCluster, ONTAP Mediator facilita una conmutación de sitios automática no planificada asistida por Mediator (MAUSO) al almacenar información de estado sobre los nodos de MetroCluster y ayudar a determinar el curso de acción adecuado durante un fallo.




[[ontap-mediator-services]]
== Servicios de ONTAP Mediator

ONTAP Mediator ofrece dos servicios systemctl adicionales:

* *`ontap_mediator.service`*
+
Mantiene el servidor de la API de REST para gestionar las relaciones de ONTAP.

* *`mediator-scst.service`*
+
Controla el inicio y el apagado del módulo iSCSI (SCST).





[[tools-provided-for-the-system-administrator]]
== Herramientas a disposición del administrador del sistema

Herramientas a disposición del administrador del sistema:

* *`/usr/local/bin/mediator_change_password`*
+
Establece una nueva contraseña de la API cuando se proporcionan el nombre de usuario y la contraseña actuales de la API.

* *`/usr/local/bin/mediator_change_user`*
+
Establece un nuevo nombre de usuario de la API cuando se facilitan el nombre de usuario y la contraseña actuales de la API.

* *`/usr/local/bin/mediator_generate_support_bundle`*
+
Genera un archivo tgz local que contiene toda la información de soporte útil necesaria para comunicarte con el soporte al cliente de NetApp. Esto incluye la configuración de la aplicación, los registros y algo de información del sistema. Los paquetes se generan en el disco local y pueden transferirse manualmente, según sea necesario. Ubicación de almacenamiento: /opt/netapp/data/support_bundles/

* *`/usr/local/bin/uninstall_ontap_mediator`*
+
Elimina el paquete ONTAP Mediator y el módulo del núcleo SCST. Esto incluye toda la configuración, los registros y los datos del buzón.

* *`/usr/local/bin/mediator_unlock_user`*
+
Desbloquea la cuenta de usuario de la API si se ha alcanzado el límite de reintentos de autenticación. Esta función se utiliza para impedir la deducción de contraseñas mediante ataques de fuerza bruta. Solicita al usuario que introduzca el nombre de usuario y la contraseña correctos.

* *`/usr/local/bin/mediator_add_user`*
+
(Solo para soporte técnico) Se utiliza para añadir el usuario de la API durante la instalación.





[[scst-and-kernel-updates]]
== SCST y actualizaciones del núcleo

ONTAP Mediator utiliza SCST para proporcionar iSCSI para la comunicación en las configuraciones de IP de MetroCluster. El paquete SCST es un módulo del kernel que se compila durante la instalación. Es posible que tengas que volver a instalar SCST después de las actualizaciones del kernel. Como alternativa, desinstala ONTAP Mediator, luego vuelve a instalar y reconfigura la relación de ONTAP. Consulta link:https://scst.sourceforge.net/["SCST: un subsistema de destino SCSI genérico para Linux"^] para saber más sobre SCST.


NOTE: Deberías coordinar cualquier actualización del kernel del SO del servidor con una ventana de mantenimiento en ONTAP.



[[support-for-https-and-iscsi]]
== Soporte para HTTPS e iSCSI

A partir de ONTAP 9.19.1 y ONTAP Mediator 1.12, puedes configurar un ONTAP Mediator que use HTTPS o iSCSI para supervisar una configuración IP de MetroCluster. Puedes elegir instalar ONTAP Mediator con soporte tanto para iSCSI como para HTTPS, o solo para HTTPS. Si ONTAP Mediator se instala con soporte solo para HTTPS, el paquete SCST no se instala. Consulta link:install/prepare-install.html#https-iscsi-installation["Opciones de instalación HTTPS e iSCSI para ONTAP Mediator"] para obtener más información.
