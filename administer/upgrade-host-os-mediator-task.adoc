= Actualizar el sistema operativo host y reinstalar o actualizar ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para actualizar el sistema operativo host de ONTAP Mediator con SCST instalado a una versión posterior, debes desinstalar ONTAP Mediator. Después de la actualización del sistema operativo, puedes reinstalar tu versión actual de ONTAP Mediator o actualizar a una versión más reciente.

.Acerca de esta tarea
* Esta tarea se aplica a las versiones de ONTAP Mediator con SCST instalado. Si instalaste ONTAP Mediator 1.12 o posterior con soporte solo para HTTPS, el paquete SCST no está instalado y puedes actualizar el sistema operativo host sin afectar a ONTAP Mediator. Consulta la documentación del proveedor del sistema operativo host para ver las instrucciones de actualización del sistema operativo.
* Si solo necesitas actualizar el kernel del sistema operativo del host a una versión compatible sin pasar a una nueva versión del sistema operativo, consulta link:host-maintenance-task.html["Mantenimiento del sistema operativo del host para ONTAP Mediator"] en su lugar.
* Antes de actualizar el sistema operativo del host para ONTAP Mediator con la herramienta leapp-upgrade, link:uninstall-mediator-task.html["desinstalar ONTAP Mediator"]. La herramienta comprueba si hay nuevas versiones de RPM en los repositorios registrados.
* El instalador de ONTAP Mediator instala un archivo .rpm, que la herramienta leapp-upgrade incluye en la búsqueda. Dado que el instalador descomprime el archivo en lugar de descargarlo de un repositorio registrado, la herramienta no puede encontrar una actualización. Debes utilizar la herramienta leapp-upgrade para desinstalar el paquete.


.Pasos
. Haz una copia de seguridad de los archivos de registro:
+
....
[rootmediator-host ~]# tar -czf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator ./log ./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]# tar -tf ontap_mediator_file_backup.tgz
./log/
./log/ontap_mediator.log
./log/scstadmin.log
./log/ontap_mediator_stdout.log
./log/ontap_mediator_requests.log
./log/install_20230419134611.log
./log/scst.log
./log/ontap_mediator_syslog.log
./ontap_mediator/server_config/ontap_mediator.user_config.yaml
[rootmediator-host ~]#
....
. Realiza la actualización con la herramienta leapp-upgrade:
+
....
[rootmediator-host ~]# leapp preupgrade --target 9.8
  ..<snip upgrade checks>..
  ..<fix issues found>..
[rootmediator-host ~]# leapp upgrade --target 9.8
  ..<snip upgrade>..
[rootmediator-host ~]# cat /etc/os-release | head -2
NAME="Red Hat Enterprise Linux"
VERSION="8.4 (Ootpa)"
[rootmediator-host ~]#
....
. Vuelve a instalar ONTAP Mediator:
+

NOTE: Realiza el resto de los pasos inmediatamente después de reinstalar ONTAP Mediator para evitar la pérdida de los archivos de registro.

+
....
[rootmediator-host ~]# ontap-mediator-1.12.1/ontap-mediator-1.12.1

ONTAP Mediator: Self Extracting Installer

  ..<snip installation>..
[rootmediator-host ~]#
....
. Detén ontap_mediator:
+
....
[rootmediator-host ~]# systemctl stop ontap_mediator
[rootmediator-host ~]#
....
. Sustituye los archivos de registro:
+
....
[rootmediator-host ~]# tar -xf ontap_mediator_file_backup.tgz -C /opt/netapp/lib/ontap_mediator
[rootmediator-host ~]#
....
. Inicia ontap_mediator:
+
....
[rootmediator-host ~]# systemctl start ontap_mediator
[rootmediator-host ~]#
....
. Vuelve a conectar todos los clústeres de ONTAP al ONTAP Mediator actualizado:

.SnapMirror active sync
--
