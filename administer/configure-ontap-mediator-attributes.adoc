= Configurar los atributos de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Puedes configurar los atributos del lado del host de ONTAP Mediator, incluidas las opciones relacionadas con los certificados y las anulaciones de configuración.



[[ontap-mediator-configurable-settings]]
== Parámetros configurables de ONTAP Mediator

ONTAP Mediator admite varios parámetros configurables. Los valores predeterminados de estos parámetros se proporcionan en un archivo `low_space_threshold_mib: 10` de solo lectura. El archivo se encuentra en:

`/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.user_config.yaml`

Todos los valores que se introduzcan en el  `ontap_mediator.user_config.yaml` anularán los valores predeterminados y se mantendrán en todas las actualizaciones de ONTAP Mediator.

Después de modificar `ontap_mediator.user_config.yaml`, reinicia ONTAP Mediator:

[source, cli]
----
systemctl restart ontap_mediator
----
Los atributos de ONTAP Mediator descritos en esta sección se pueden modificar si es necesario.


NOTE: No debes cambiar los demás valores predeterminados del `ontap_mediator.config.yaml` porque los valores modificados no se conservan durante las actualizaciones de ONTAP Mediator.

Modifica los atributos de ONTAP Mediator copiando las variables necesarias en el archivo  `ontap_mediator.user_config.yaml` para anular la configuración predeterminada.



[[install-third-party-ssl-certificates]]
== Instalar certificados SSL de terceros

Puedes sustituir los certificados autofirmados predeterminados por certificados SSL de terceros modificando los archivos de configuración de ONTAP Mediator.

Para sustituir los certificados autofirmados predeterminados por certificados SSL de terceros, modifica determinados atributos en los siguientes archivos:

* `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.config.yaml`
* `/opt/netapp/lib/ontap_mediator/uwsgi/ontap_mediator.ini`


Las variables de estos archivos sirven para controlar los archivos de certificados que utiliza ONTAP Mediator.

[[configure-password-attack-protection]]
== Configurar la protección contra ataques a la contraseña

Los siguientes ajustes ofrecen protección contra ataques de adivinación de contraseñas por fuerza bruta.

Para activar la función, asigna un valor a  `window_seconds` y a  `retry_limit`.

.Ejemplos:
--
* Da un margen de 5 minutos para que se hagan conjeturas y luego restablece el recuento a cero fallos:
+
`authentication_lock_window_seconds: 300`

* Bloquea la cuenta si se producen cinco fallos dentro del plazo establecido:
+
`authentication_retry_limit: 5`

* Reduce el impacto de los ataques de fuerza bruta para adivinar contraseñas estableciendo un retraso que ocurre antes de rechazar cada intento, lo que ralentiza los ataques.
+
`authentication_failure_delay_seconds: 5`

+
....
authentication_failure_delay_seconds: 0   # seconds (float) to delay failed auth attempts prior to response, 0 = no delay
authentication_lock_window_seconds: null  # seconds (int) since the oldest failure before resetting the retry counter, null = no window
authentication_retry_limit: null          # number of retries to allow before locking API access, null = unlimited
....


--


[[configure-password-complexity-rules]]
== Configurar las reglas de complejidad de las contraseñas

Los siguientes campos controlan las reglas de complejidad de la contraseña de la cuenta de usuario de la API de ONTAP Mediator.

....
password_min_length: 8

password_max_length: 64

password_uppercase_chars: 0    # min. uppercase characters

password_lowercase_chars: 1    # min. lowercase character

password_special_chars: 1      # min. non-letter, non-digit

password_nonletter_chars: 2    # min. non-letter characters (digits, specials, anything)
....
Configura los parámetros de espacio en disco y de registro de ONTAP Mediator, incluidos el umbral de espacio libre y el espacio reservado para registros.



[[configure-the-free-space-threshold]]
== Configurar el umbral de espacio libre

Hay ajustes que controlan el espacio libre necesario en el `/opt/netapp/lib/ontap_mediator` disco.

Si el espacio es inferior al umbral establecido, el servicio emite un evento de advertencia.

....
low_space_threshold_mib: 10
....


[[configure-reserved-log-space]]
== Configura el espacio reservado para los registros

La función  `RESERVE_LOG_SPACE` se controla mediante ajustes específicos. De forma predeterminada, la instalación de ONTAP Mediator crea un espacio en disco independiente para los registros. El instalador crea un nuevo archivo de tamaño fijo con un total de 700MB de espacio en disco para usarlo exclusivamente para el registro de ONTAP Mediator.

Para desactivar esta función y usar el espacio en disco predeterminado, realiza los siguientes pasos:

. Cambia el valor de RESERVE_LOG_SPACE de 1 a 0 en el siguiente archivo:
+
`/opt/netapp/lib/ontap_mediator/tools/mediator_env`

+
.. Ejecuta el siguiente comando:
+
[source, cli]
----
cat /opt/netapp/lib/ontap_mediator/tools/mediator_env | grep "RESERVE_LOG_SPACE"
----
+
....
RESERVE_LOG_SPACE=0
....
.. Reinicia ONTAP Mediator:
+
[source, cli]
----
systemctl restart ontap_mediator
----




--
Para volver a activar la función, cambia el valor de 0 a 1 y reinicia Mediator.


NOTE: Al cambiar de espacio en disco, no se eliminan los registros existentes. Todos los registros anteriores se respaldan y luego se mueven al espacio en disco actual después de cambiar y reiniciar el Mediator.
