= Comprobar el estado de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Comprueba que ONTAP Mediator funcione correctamente.



[[verify-the-service-status]]
== Comprueba el estado del servicio

.Pasos
. Ver el estado de ONTAP Mediator:
+
.. Ejecuta el siguiente comando:
+
[source, cli]
----
systemctl status ontap_mediator
----
+
[listing]
----
[root@mediator_host ~]# systemctl status ontap_mediator

.. Consulta el estado del servicio SCST:
+

NOTE: Si instalaste ONTAP Mediator 1.12 o posterior con soporte solo para HTTPS, el paquete SCST no está instalado y puedes omitir esta tarea.

+
[source, cli]
----
systemctl status mediator-scst
----
+
[listing]
----
[root@mediator_host ~]# systemctl status mediator-scst

[[confirm-the-listening-ports]]
== Confirma los puertos de escucha

. Comprueba los puertos que utiliza ONTAP Mediator:
+
[source, cli]
----
netstat -anlt | grep -E '3260|31784'
----
+
[listing]
----
[root@scspr1905507001 ~]# netstat -anlt | grep -E '3260|31784'

         tcp   0   0 0.0.0.0:31784   0.0.0.0:*      LISTEN

         tcp   0   0 0.0.0.0:3260    0.0.0.0:*      LISTEN

         tcp6  0   0 :::3260         :::*           LISTEN
----
