= Actualizar ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para actualizar ONTAP Mediator a una versión más reciente sin actualizar el sistema operativo del host, descarga el paquete de instalación de la nueva versión y ejecuta el instalador en el host en el que ya está instalado ONTAP Mediator.


NOTE: Si necesitas actualizar el sistema operativo del host a una nueva versión y reinstalar o actualizar ONTAP Mediator como parte de ese proceso, consulta link:upgrade-host-os-mediator-task.html["Actualizar el SO host y ONTAP Mediator"] en su lugar.

.Antes de empezar
* Comprueba que tu host cumpla los requisitos previos descritos en link:../install/prepare-install.html["Prepárate para instalar ONTAP Mediator"], incluidos los requisitos del host, el firewall y el sistema operativo.
* Descarga el paquete de instalación de la nueva versión. Consulta link:../install/download-install-pkg-task.html["Descarga el paquete de instalación de ONTAP Mediator"].
* NetApp recomienda verificar la firma digital del nuevo paquete de instalación. Consulta link:../install/verify-code-signature-task.html["Comprueba la firma digital del paquete de instalación de ONTAP Mediator"].


.Acerca de esta tarea
Revisa la siguiente información antes de actualizar ONTAP Mediator.

* Deberías actualizar ONTAP Mediator a la última versión. Las versiones anteriores siguen funcionando con todas las versiones de ONTAP, pero las más recientes incluyen parches de seguridad para componentes de terceros.
* Cuando actualizas a una nueva versión de ONTAP Mediator que incluye el paquete SCST, el instalador actualiza automáticamente a la versión recomendada de SCST, a menos que haya disponible una versión superior. Para instrucciones sobre cómo instalar manualmente una versión superior de SCST, consulta link:host-maintenance-task.html["Mantenimiento del sistema operativo del host para ONTAP Mediator"]. Para las versiones compatibles, consulta el link:../release-notes/support-matrix.html#scst-support-matrix["Matriz de compatibilidad de SCST"].


[NOTE]
====
* Si la actualización falla, puede que tengas que probar una versión más reciente de ONTAP Mediator.
* A partir del 15 de junio de 2025, no puedes instalar ni actualizar ONTAP Mediator 1.9 y 1.8 porque sus certificados de firma de código han caducado. Si la actualización falla, usa en su lugar la versión de parche ONTAP Mediator 1.9.1.


====
* A partir de ONTAP 9.19.1 y ONTAP Mediator 1.12, tienes la opción de instalar ONTAP Mediator con compatibilidad con iSCSI y HTTPS, o compatibilidad solo con HTTPS. Si eliges instalar ONTAP Mediator con compatibilidad solo con HTTPS, el paquete SCST no se instala.
* Si actualizas desde ONTAP Mediator 1.11 o anterior con SCST instalado y eliges la opción solo HTTPS durante la actualización, el paquete SCST se desinstala y la nueva versión de ONTAP Mediator no contiene el paquete SCST.
* Si tienes previsto utilizar ONTAP Mediator para supervisar varias configuraciones de IP de MetroCluster, la compatibilidad depende de tu tipo de Mediator, la versión de ONTAP y el sistema operativo. Consulta link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utiliza ONTAP Mediator para supervisar varias configuraciones de MetroCluster IP"^] para obtener más información.
* La instalación de ONTAP Mediator con soporte solo para HTTPS es compatible con los siguientes casos de uso:
+
** Tienes previsto utilizar ONTAP Mediator únicamente para supervisar tus clústeres de sincronización activa de SnapMirror.
** Tienes pensado configurar ONTAP Mediator con HTTPS para supervisar una o varias configuraciones de IP de MetroCluster.


* ONTAP Mediator debe estar instalado con soporte para iSCSI y HTTPS en el siguiente escenario:
+
** Tienes previsto configurar ONTAP Mediator con iSCSI para supervisar una o varias configuraciones IP de MetroCluster.




* Al ejecutar el instalador en una instalación existente de ONTAP Mediator, este detecta la versión actual y te pide que confirmes la actualización:
+
`ONTAP Mediator will be upgraded from version <current-version> to <new-version>.`

+
`Do you wish to continue? Y(es)/n(o):`

* Como parte de la actualización, el instalador crea un paquete de soporte con la configuración previa a la actualización y migra la base de datos antes de actualizar el software ONTAP Mediator.
* En los casos de uso de automatización, puedes usar el comando  `./ontap-mediator-1.13.0/ontap-mediator-1.13.0 -y` para saltarte las indicaciones del instalador.


.Pasos
. Antes de la actualización, completa el siguiente subpaso si vas a actualizar a ONTAP Mediator 1.13 o una versión posterior en una instancia de ONTAP Mediator que esté emparejada con una de las siguientes versiones:
+
** ONTAP 9.11.1 y versiones anteriores
** Versiones de parche de ONTAP anteriores a 9.12.1P15, 9.13.1P12, 9.14.1P8 y 9.15.1P2
+
... Añade la siguiente línea al archivo  `/opt/netapp/lib/ontap_mediator/ontap_mediator/server_config/ontap_mediator.user_config.yaml`.
+
`'generate_unique_ca_name': false`

+
Este archivo se conserva tras las actualizaciones de ONTAP Mediator.





. Ejecuta el instalador de la nueva versión y sigue las instrucciones que te vayan apareciendo:
+
[source, cli]
----
./ontap-mediator-1.13.0/ontap-mediator-1.13.0
----
+
[NOTE]
====
Para omitir la comprobación de la firma durante la actualización, utiliza el comando 
`./ontap-mediator-1.13.0/ontap-mediator-1.13.0 --skip-code-signature-check`

====
+
El instalador detecta la instalación existente y te pide que actualices, luego instala los paquetes necesarios y migra tu configuración.
