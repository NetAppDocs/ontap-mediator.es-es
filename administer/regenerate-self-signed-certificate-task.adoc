= Regenerar un certificado temporal autofirmado para el host de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Regenerar un certificado autofirmado temporal para el host actual cuando un cambio en el nombre de host o en la dirección IP invalide el certificado existente.


NOTE: Este procedimiento solo es compatible con sistemas que ejecutan ONTAP Mediator 1.7 o una versión posterior.

.Acerca de esta tarea
* Realiza esta tarea en el host Linux en el que hayas instalado ONTAP Mediator.
* Solo puedes realizar esta tarea si los certificados autofirmados generados han quedado obsoletos debido a cambios en el nombre de host o en la dirección IP del host después de instalar ONTAP Mediator.
* Una vez que el certificado autofirmado temporal haya sido sustituido por un certificado de confianza de un tercero, _no_ utilices esta tarea para volver a generar un certificado. La ausencia de un certificado autofirmado provocará que este procedimiento falle.


.Paso
Para generar un nuevo certificado temporal autofirmado para el host actual, realiza el siguiente paso:

. Reinicia ONTAP Mediator:
+
`./make_self_signed_certs.sh overwrite`
