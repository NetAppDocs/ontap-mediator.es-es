= Novedades de ONTAP Mediator
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Cada versión incluye nuevas mejoras para ONTAP Mediator.


NOTE: Para obtener información sobre las versiones del sistema operativo y de SCST, consulta link:support-matrix.html["Matriz de soporte"].

[cols="25,75"]
|===


| Versión de ONTAP Mediator | Mejoras 


 a| 
1.12.1
 a| 
* Soporte para RHEL:
+
** Compatible: 10.1 y 9.7.
** Recomendado: 10.2, 10.0, 9.8, 9.6, 9.4 y 8.10.


* Soporte para Rocky Linux 10.2, 9.8 y 8.10.
* Soporte para Oracle Linux 10.1 y 9.8 con ambos kernels rhck y uek.
* A partir de ONTAP Mediator 1.12.1 y ONTAP 9.19.1, una única instancia de ONTAP Mediator configurada con HTTPS puede supervisar simultáneamente las siguientes configuraciones:
+
** Un máximo de diez configuraciones IP de cuatro nodos o cinco de ocho nodos de MetroCluster si se instalan en un host con una CPU de 8 núcleos y al menos 16 GB de RAM. Consulta link:https://docs.netapp.com/us-en/ontap-metrocluster/install-ip/concept_mediator_requirements.html#mediator-multiple-mccip["Utiliza ONTAP Mediator para supervisar varias configuraciones de MetroCluster IP"^].
** Una configuración IP de MetroCluster de cuatro nodos y una relación entre iguales activa de SnapMirror si se instala en un host con una CPU de 2 núcleos. Consulta link:https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/mediator-install-task.html#ontap-mediator["Configura ONTAP Mediator para SnapMirror active sync"^].


* Incluye una nueva herramienta para reparar una instalación de SCST dañada. Después de instalar ONTAP Mediator, puedes encontrar la herramienta en `/usr/local/bin/mediator_repair_scst`. Puedes usar la herramienta después de una actualización del sistema operativo, si el sistema operativo actualizado requiere un parche de SCST que no está disponible en el paquete predeterminado de SCST.

1,12
 a| 
* Soporte para RHEL:
+
** Compatible: 10.1 y 9.7.
** Recomendado: 10.2, 10.0, 9.8, 9.6, 9.4 y 8.10.


* Soporte para Rocky Linux 10.2, 9.8 y 8.10.
* Soporte para Oracle Linux 10.1 y 9.7 con ambos kernels rhck y uek.
* A partir de ONTAP 9.19.1 y ONTAP Mediator 1.12, puedes configurar un ONTAP Mediator que use HTTPS para la comunicación en configuraciones IP de MetroCluster. HTTPS ofrece mayor seguridad al cifrar sesiones completas usando SSL/TLS. Puedes elegir instalar ONTAP Mediator con soporte solo para HTTPS. El paquete SCST no se instala si usas este método de instalación. link:../install/prepare-install.html#https-iscsi-installation["Más información sobre las opciones de instalación de HTTPS e iSCSI para ONTAP Mediator"].
