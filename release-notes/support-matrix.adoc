* «Sí» significa que el sistema operativo es el recomendado para la instalación de ONTAP Mediator y que es totalmente compatible y tiene soporte.
* «No» significa que el sistema operativo y ONTAP Mediator no son compatibles.
* "Compatible" significa que Red Hat ya no ofrece soporte para estas versiones de RHEL, pero aún puedes instalar ONTAP Mediator en ellas.
* ONTAP Mediator 1.6 añade compatibilidad con Rocky Linux 9 y 8.
* ONTAP Mediator 1.5 fue la última versión compatible con los sistemas operativos de la rama RHEL 7.x.
* CentOS 8 se eliminó de todas las versiones debido a su cambio de rama. CentOS Stream se consideró que no es un sistema operativo adecuado para producción. No se planea soporte.
